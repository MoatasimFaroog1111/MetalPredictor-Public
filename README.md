# MetalPredictor Public CI Mirror

This repository is a sanitized public snapshot used for continuous integration and deployment validation of the MetalPredictor live forecasting platform.

- No private Git history is copied here.
- No API keys, tokens, passwords, or runtime secrets belong in this repository.
- Live credentials must be supplied only through deployment or GitHub Actions secrets.
- The forecasting system is research-only; predictive edge is not proven and BUY/SELL execution is disabled.
